Parquet·Arrow·Avro 파일을
브라우저에서 바로 열어 봅니다

파일은 이 컴퓨터를 떠나지 않습니다. 수 GB 파일도 필요한 부분만 읽어서, 스키마와 앞쪽 행을 바로 보여 줍니다.

여기에 파일을 놓으세요

.parquet, .arrow, .feather, .arrows, .avro

  • 올리지 않습니다. 서버도 계정도 없습니다. 파일 내용과 이름을 어디에도 저장하지 않습니다.
  • 필요한 만큼만 읽습니다. Parquet은 고른 컬럼과 해당 row group만, Avro는 블록 단위로 읽습니다.
  • 값을 바꾸지 않습니다. int64, decimal, 마이크로·나노초 timestamp를 원래 정밀도 그대로 보여 줍니다.
