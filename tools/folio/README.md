# Folio — 나만의 문서 열람실

PPTX, HWP, HWPX, XLSX, DOCX를 서버 업로드 없이 브라우저 메모리에서 열어보는 정적 웹 앱입니다. TypeScript + Vite로 구현했으며 백엔드·계정·분석 도구·문서 저장소가 없습니다.

## 실행

Node.js 22.12+ 또는 지원되는 최신 LTS가 필요합니다.

```sh
npm ci
npm run dev
```

배포 빌드 확인:

```sh
npm run build
npm run preview -- --port 4173 --strictPort
```

주소: http://127.0.0.1:4173

## 기능과 제한

- 파일 선택 / 드래그앤드롭, 페이지·시트 이동, 확대·축소, 너비 맞춤, 닫기.
- 파일당 30 MB. OOXML/HWPX ZIP 확장 크기 100 MB와 압축 구조 제한.
- HWP 5.x와 HWPX: Rust/WASM 기반 페이지 렌더링. HWP 3.x와 암호화 파일은 미지원.
- PPTX: SVG 슬라이드 미리보기. 전환·애니메이션·동영상 및 일부 도형·차트는 재현되지 않습니다.
- DOCX: 본문·표·이미지. 페이지 경계와 글꼴은 Word와 다를 수 있습니다.
- XLSX: 저장된 셀 값·병합 셀·기본 셀 서식(배경/글자/테마 색상, 글꼴, 정렬, 테두리, 행 높이/열 너비). 드래그 범위 선택과 복사 지원. SUM·IF 등 기본 수식과 시트 간 참조를 로컬 재계산합니다. 미지원 수식은 저장된 결과를 유지하고 경고합니다. 조건부 서식·차트는 미지원. 최대 1000행·100열·30000셀 범위 표시.
- 모든 지원 형식을 PDF로 다운로드합니다. 전체 미리보기 페이지/시트를 이미지로 변환하므로 PDF 텍스트 검색·선택은 지원하지 않습니다. 큰 시트는 여러 페이지로 나누며 표시 제한 밖의 내용은 포함하지 않습니다. 변환 중 취소할 수 있습니다.
- 최대 500페이지/시트. 한글·엑셀의 초과 범위는 경고와 함께 일부만 표시합니다.
- 최신 Chrome/Edge에서 검증. 한글 렌더러는 처음 사용할 때 약 11.8 MB WASM 자산을 내려받습니다.

## 개인정보 경계

파일은 File API로 읽어 작업 스레드 또는 임시 DOCX 렌더링 프레임에 전달합니다. 표시할 결과는 정화 후 스크립트 실행이 없는 sandbox iframe에서 보여줍니다. 외부 리소스는 CSP로 차단하며 DOCX의 외부 관계도 제거합니다. 매크로는 실행하지 않습니다. 허용된 수식만 제한된 계산기로 처리하며 외부 데이터 함수는 차단합니다.

파일 교체·닫기·새로고침 시 worker와 임시 프레임을 없애고 문서 참조를 해제합니다. 앱은 선택 파일·파일명·열람 기록을 localStorage, sessionStorage, IndexedDB, 쿠키, 서버에 저장하지 않습니다. 브라우저/OS의 메모리·캐시 동작과 강제 보안 삭제까지 보장하는 도구는 아닙니다. 정적 앱 자산 다운로드는 발생합니다.

## 검증

```sh
npm test
npx playwright install chromium
npm run test:e2e -- --workers=1
```

- 14개 단위 테스트: 수식 계산·참조·계산 한도와 형식/용량, 파일 시그니처, ZIP 손상·암호·압축 해제 예산·경로 검사.
- 18개 Chromium 시나리오: PDF 다운로드·취소·페이지 분할, 수식 계산, 셀 선택·서식과 실제 형식의 합성 문서 5종 열기, 페이지/시트 이동, 재열기, 잘못된 파일, 외부 요청 여부, 모바일, 확대, 새로고침 후 초기화.
- 테스트 문서는 `tests/generate-fixtures.mjs`로 생성합니다. 개인 문서를 포함하지 않습니다. 모든 실제 문서의 원본 재현 품질을 보증하는 테스트는 아닙니다.

## 배포

이 도구는 `carpenta.github.io` 저장소의 `tools/folio/`에 있고 `https://carpenta.github.io/tools/folio/`로 서비스됩니다. 저장소 루트의 `.github/workflows/pages.yml`이 테스트와 빌드를 실행한 뒤 사이트와 함께 배포합니다. `base: './'`이므로 하위 경로에서 그대로 동작합니다.

설계는 [docs/DESIGN.md](docs/DESIGN.md), 의존성 출처는 [docs/DEPENDENCIES.md](docs/DEPENDENCIES.md)를 참조하세요.
