# Fairway Note — 에버리스 동코스 스코어 노트

라운드 중 휴대폰으로 홀마다 드라이버·어프로치·퍼트 타수를 버튼으로 세고, OB와 멀리건을 함께 표시하는 정적 웹 앱입니다. 합계와 라운드 분석을 입력하는 즉시 보여 줍니다. TypeScript + Vite로 만들었고 런타임 의존성, 백엔드, 계정, 분석 도구가 없습니다.

## 실행

Node.js 22.12 이상이 필요합니다.

```sh
npm ci
npm run dev
```

배포 빌드 확인:

```sh
npm run build
npm run preview -- --port 4175 --strictPort
```

주소: http://127.0.0.1:4175

CSP 때문에 `npm run dev`에서는 자동 새로고침(HMR)과 Vite가 넣는 스타일이 막힙니다. 화면은 빌드 후 미리보기로 확인합니다.

## 기능과 제한

- 18홀(전반 1–9, 후반 10–18). 홀마다 Par 3·4·5를 고를 수 있고 기본값은 모두 Par 4입니다.
- 홀마다 세는 항목
  - 드라이버: 티샷. OB 뒤 다시 친 티샷도 여기에 셉니다.
  - 어프로치: 두 번째 샷부터 그린에 올리기 전까지의 샷
  - 퍼터: 그린 위 퍼트
  - OB: 한 번에 1벌타가 타수에 더해집니다. 다시 친 샷은 드라이버나 어프로치로 따로 셉니다.
  - 멀리건: 표시만 하고 타수에 넣지 않습니다.
- 홀 타수 = 드라이버 + 어프로치 + 퍼터 + OB. 한 항목은 0–15까지 셀 수 있습니다.
- 지금 치고 있는 홀은 퍼트를 넣기 전까지 "진행 중"으로 보이고 합계·스코어카드·분석에 넣지 않습니다(티샷만 친 홀이 이글로 잡히지 않게). 퍼트 없이 끝난 홀(칩인)은 다음 홀로 넘어가면 들어갑니다.
- 위쪽 합계(총타·Par 대비·기록한 홀·퍼트·OB·멀리건)는 화면을 내려도 따라옵니다.
- 스코어카드: 전반·후반 표와 OUT·IN·합계. 홀 번호를 누르면 그 홀로 갑니다.
- 라운드 분석(기록한 홀만 대상)
  - 평균 퍼트, 1퍼트·3퍼트 이상 홀 수
  - 그린 적중(GIR): 퍼트가 있고 드라이버 + 어프로치 + OB ≤ Par − 2인 홀
  - 스코어 분포(이글 이하 ~ 트리플 이상), Par별 평균, 가장 잘한·아쉬운 홀
  - 영역별 잃은 타수: 홀마다 티샷 1, 어프로치 Par − 3, 퍼트 2를 기준으로 더 친 타수와 OB 벌타. 기준보다 적게 친 홀이 다른 홀의 손실을 지우지 않습니다. 가장 많이 잃은 영역(같으면 모두)을 알려 줍니다.
- 다른 날 기록하던 라운드가 남아 있으면 열 때 "이어서 기록 / 새 라운드 시작"을 묻습니다.
- 같은 브라우저의 다른 탭에서 기록하면 열려 있는 탭도 그 기록으로 바뀝니다.
- 접근성: 탭할 때마다 하나의 알림 영역이 "3번 홀 퍼터 2, 5타"처럼 읽어 주고, Par 선택은 화살표 키로 움직입니다.
- 제한
  - 에버리스 "동코스"의 홀별 Par를 공개 자료에서 확인하지 못해 기본값을 모두 Par 4로 두었습니다. 라운드 중 홀마다 고칩니다.
  - 라운드 하나만 기록합니다. 지난 라운드 보관, 동반자 스코어, 거리 측정은 없습니다.
  - 화면 문구는 한국어만 있습니다.
- 최신 Chrome에서 검증했습니다.

## 개인정보 경계

입력한 라운드는 이 브라우저의 localStorage(`fairway-note:round:v1`) 한 곳에만 저장해 새로고침이나 화면 꺼짐 뒤에도 이어서 기록할 수 있게 합니다. "새 라운드 시작"을 누르면 지웁니다. 서버로 보내지 않고, sessionStorage·IndexedDB·쿠키는 쓰지 않습니다. 저장할 수 없는 환경(일부 개인정보 보호 모드)에서는 화면 아래에 그렇게 알리고 메모리에서만 동작합니다.

CSP 메타 태그가 네트워크 연결(`connect-src 'none'`)과 다른 출처의 스크립트·스타일·이미지, 인라인 스타일 태그를 막습니다. 그래서 `npm run dev`에서는 Vite가 넣는 스타일도 막히니 화면 확인은 `npm run build && npm run preview`로 합니다.

## 검증

```sh
npm test
npx playwright install chromium
npm run test:e2e -- --workers=1
```

- 단위 테스트(Vitest)
  - 홀 타수, OB 벌타, 멀리건 제외, 0–15 범위
  - 진행 중인 홀과 칩인 처리
  - GIR, 스코어 이름, 합계, 분석(분포·Par별 평균·영역별 손실·동률·가장 잘한/아쉬운 홀)
  - 저장·복원, 깨진 값(없는 날짜 포함) 무시, 저장소 예외
- e2e(Playwright Chromium)
  - 탭으로 기록, 빼기, Par 변경, 합계와 스코어카드
  - 분석 문구
  - 새로고침 뒤 복원, 새 라운드 확인·취소, 깨진 저장 값
  - 스코어카드에서 홀 이동, 처음·끝 홀
  - 진행 중인 홀, 칩인, 멀리건만 있는 홀, 15에서 멈춤
  - 스코어카드에서 이동한 뒤 홀 제목이 위쪽 합계에 가리지 않음, Par 화살표 키, 알림 영역
  - 저장할 수 없는 환경, 지난 라운드 안내, 다른 탭과 동기화
  - 콘솔 오류·CSP 위반 없음, 외부 요청 없음, 라운드 키 외에 저장소 사용 없음, `../../` 링크, 360px 폭에서 가로 스크롤 없음
