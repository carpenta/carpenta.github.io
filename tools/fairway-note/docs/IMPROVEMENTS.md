# Fairway Note 개선 기록

버전마다 무엇을 왜 바꿨는지 쌓아 두는 기록입니다. 새 버전이 맨 위에 옵니다. 앱 안의 버전 표시는 `src/version.ts` 한 곳에서 옵니다.

## 전략

- 목표: 라운드 중 한 손으로 홀을 몇 초 만에 기록하고, 끝나면 어디서 타수를 잃었는지 보는 앱. 사용성·디자인·기능 모두 TheGrint의 홀 기록 화면만큼 다듬어진 수준을 목표로 합니다.
- 지금 방향
  - 기록 화면은 TheGrint의 구성과 입력 방식을 따릅니다: 위쪽 홀 전환, 큰 원형 점수 배지, 흰 시트 안의 세로 알약 스테퍼, 기본/상세 전환, 넓은 "다음 홀", 어두운 아래 탭.
  - 점수는 입력하지 않고 계산합니다: 드라이버 + 어프로치 + 퍼터 + OB + 해저드.
- TheGrint에서 가져오는 것: 화면 구성, 알약 스테퍼, 상세 모드의 티샷 방향 패드와 미스샷, 벌타 아이콘 줄, 점수 배지 자리.
- 우리 것: 잔디색(터프·페어웨이·러프·그린), 직접 그린 홀 그림을 화면 배경으로, 클럽 아이콘과 말뚝 아이콘, 한국어 문구, 스코어카드 표시(◎ ○ □ ⧈), 클럽별 스윙 수로 계산되는 점수.
- 지키는 것
  - 다른 앱의 이미지·아이콘·문구(예: HIT, Mis-Hit)와 남색+라임 색을 쓰지 않습니다. 홀 그림은 직접 그리고, 실제 배치는 골프장 공식 홀 안내로 링크합니다.
  - 오프라인에서 동작하고, 네트워크 요청·계정·분석 도구가 없습니다.
  - 버튼은 48px 이상, 375×553에서 기본 화면이 스크롤 없이 들어옵니다.

## v4 — 2026-11-20

- 바뀐 것
  - 기록 화면을 TheGrint식 구성으로 새로 짰습니다.
    - 위쪽: 메뉴, ‹ 깃발 "N번 홀" ›, Par·거리·HDCP·홀 메모·공식 홀 안내 칩, 홈(사이트로 돌아가기).
    - 오른쪽 위 원형 배지에 홀 타수와 스코어카드 표시, 이름(파·보기·이글·홀인원 등)이 나옵니다. 언더파는 빨강, 파는 터프, 그 밖은 짙은 녹색입니다.
    - 흰 시트 안에 드라이버·어프로치·퍼터 알약 스테퍼가 있고, 그 아래 OB·해저드 버튼과 마지막 벌타를 빼는 "빼기"가 있습니다.
    - 상세 모드에는 티샷 방향 패드(페어웨이, 좌·우, 많이 좌·우, 김·짧음)와 미스샷(헛스윙, 뒤땅/토핑)이 더해집니다. 첫 드라이버 샷의 세부로 저장되고, 드라이버가 0이면 티샷 하나를 먼저 셉니다. Par 3에서는 가운데가 "온그린"입니다.
  - 화면 배경에 지금 홀을 직접 그립니다. 티는 아래, 그린과 깃발은 위에 두고, Par 3은 가까운 큰 그린, Par 4·5는 페어웨이입니다. 홀마다 핀 위치와 그린 모양이 바뀌고, 홀 메모에 도그렉이 있으면 그쪽으로 휩니다. 벙커나 물은 지어내지 않습니다.
  - 스코어카드 화면: 합계(타수·파 대비·퍼트·OB·해저드), 9홀씩 홀 칸(누르면 그 홀을 기록 화면에 엶), 지금 홀 표시, 합계 줄, "타수를 잃은 곳", 분석, 보내기, 새 라운드를 둡니다.
  - 아래 탭은 짙은 터프색이고, 오른쪽에 버전 "v4"가 조용히 보입니다.
  - 멀리건과 Par 바꾸기는 메뉴로 옮겼습니다. 메뉴에는 코스와 버전도 나옵니다.
  - 코스 데이터의 홀 메모에서 티 이름 없는 거리("385m")와 핸디캡(HDCP)을 보여 줍니다.
  - 시안을 `design/v4.html`에 둡니다. 빌드·배포되지 않는 참고용입니다.
- 이유(참고한 앱·인사이트)
  - 사용자가 TheGrint 홀 기록 화면의 구성과 입력 방식을 그대로 따르자고 했습니다. 한 화면에 홀 하나, 큰 스테퍼, 기본/상세로 나눈 입력이 현장에서 가장 빠르다는 판단입니다.
  - 배경의 홀 그림은 Hole19·Golfshot처럼 "지금 이 홀"이 바로 보이게 하려는 것입니다. 그림은 직접 그립니다.
  - 시안에서 알려진 두 문제 중 하나를 이번에 고쳤습니다. 알약 안 숫자가 +/− 버튼과 겹치던 것을, 버튼을 48px로 하고 숫자 크기를 화면 높이에 맞춰 8px 이상 띄웠습니다.
