# Fairway Note 개선 기록

버전마다 무엇을 왜 바꿨는지 쌓아 두는 기록입니다. 새 버전이 맨 위에 옵니다. 앱 안의 버전 표시는 `src/version.ts` 한 곳에서 옵니다.

## 전략

- 목표: 라운드 중 한 손으로 홀을 몇 초 만에 기록하고, 끝나면 어디서 타수를 잃었는지 보는 앱. 사용성·디자인·기능 모두 TheGrint의 홀 기록 화면만큼 다듬어진 수준을 목표로 합니다.
- 지금 방향
  - 기록 화면은 TheGrint의 구성과 입력 방식을 따릅니다: 위쪽 홀 전환, 큰 원형 점수 배지, 흰 시트 안의 세로 알약 스테퍼, 기본/상세 전환, 넓은 "다음 홀", 어두운 아래 탭.
  - 점수는 입력하지 않고 계산합니다: 드라이버 + 어프로치 + 퍼터 + OB + 해저드.
- TheGrint에서 가져오는 것: 화면 구성, 알약 스테퍼, 상세 모드의 티샷 방향 패드와 미스샷, 벌타 아이콘 줄, 점수 배지 자리.
- 우리 것: 잔디색(터프·페어웨이·러프·그린), 직접 그린 홀 그림을 화면 배경으로, 클럽 아이콘과 말뚝 아이콘, 한국어 문구, 스코어카드 표시(◎ ○ □ ⧈), 클럽별 스윙 수로 계산되는 점수.
- 지키는 것
  - 다른 앱의 이미지·아이콘·문구(예: HIT, Mis-Hit)와 남색+라임 색을 쓰지 않습니다. 홀 그림은 직접 그리고, 실제 배치는 골프장 공식 홀 안내로 링크합니다.
  - 오프라인에서 동작하고, 네트워크 요청·계정·분석 도구가 없습니다.
  - 버튼은 48px 이상, 375×553에서 기본 화면이 스크롤 없이 들어옵니다.

시안을 옮길 때 정해 둔 것
- v8: 라운드 중간에 뜨는 도움말 안내는 넣지 않습니다. 첫 탭 전에 한 번 나오는 안내와 앱 정보로 대신합니다. 홀 번호의 깃발 아이콘은 빼도 됩니다. 코스 선택에서 18홀/9홀을 고르고, 진행 칩은 "7홀"처럼 씁니다.
- v9: 길게 누르기 안내를 봤다는 표시는 세션을 넘어 기억하되 새 저장 키를 만들지 않고 코스 기억 키(`fairway-note:prefs:v1`)에 둡니다. HDCP는 코스 데이터에 공식 핸디캡이 있을 때만 보입니다.
