# Fairway Note 개선 기록

버전마다 무엇을 왜 바꿨는지 쌓아 두는 기록입니다. 새 버전이 맨 위에 옵니다. 앱 안의 버전 표시는 `src/version.ts` 한 곳에서 옵니다.

## 전략

- 목표: 라운드 중 한 손으로 홀을 몇 초 만에 기록하고, 끝나면 어디서 타수를 잃었는지 보는 앱. 사용성·디자인·기능 모두 TheGrint의 홀 기록 화면만큼 다듬어진 수준을 목표로 합니다.
- 지금 방향
  - 기록 화면은 TheGrint의 구성과 입력 방식을 따릅니다: 위쪽 홀 전환, 큰 원형 점수 배지, 흰 시트 안의 세로 알약 스테퍼, 기본/상세 전환, 넓은 "다음 홀", 어두운 아래 탭.
  - 점수는 입력하지 않고 계산합니다: 드라이버 + 어프로치 + 퍼터 + OB + 해저드.
- TheGrint에서 가져오는 것: 화면 구성, 알약 스테퍼, 상세 모드의 티샷 방향 패드와 미스샷, 벌타 아이콘 줄, 점수 배지 자리.
- 우리 것: 잔디색(터프·페어웨이·러프·그린), 직접 그린 홀 그림을 화면 배경으로, 클럽 아이콘과 말뚝 아이콘, 한국어 문구, 스코어카드 표시(◎ ○ □ ⧈), 클럽별 스윙 수로 계산되는 점수.
- 지키는 것
  - 다른 앱의 이미지·아이콘·문구(예: HIT, Mis-Hit)와 남색+라임 색을 쓰지 않습니다. 홀 그림은 직접 그리고, 실제 배치는 골프장 공식 홀 안내로 링크합니다.
  - 오프라인에서 동작하고, 네트워크 요청·계정·분석 도구가 없습니다.
  - 버튼은 48px 이상, 375×553에서 기본 화면이 스크롤 없이 들어옵니다.

## v6 — 2026-11-20 01:54

- 바뀐 것
  - 아래 탭이 셋입니다: 스코어카드 · 기록(가운데) · 지난 라운드. 고른 탭은 아이콘 뒤에 옅은 알약이 깔립니다. 홈 링크는 탭 막대 왼쪽에 그대로 두고, 오른쪽을 비워 기록이 가운데에 오게 했습니다. 버전 표시는 기록 화면 오른쪽 위(600px 아래 화면에서는 숨김)와 메뉴의 앱 정보로 옮겼습니다.
  - 지난 라운드 화면: 맨 위 "지금 라운드"(코스·날짜·기록한 홀, 타수와 파 대비, 이어서 기록), 그 아래 보관한 라운드의 추세와 목록. 라운드를 누르면 읽기 전용 창이 열립니다.
  - 메뉴를 아래에서 올라오는 목록으로 바꾸고, 항목을 누르면 그 자리에 펼쳐지게 했습니다: 새 라운드(지금 라운드가 어떻게 되는지 보여 주고 시작), 코스 바꾸기(기록한 타수는 두고 코스와 Par만 바꿈), 결과 보내기, 백업과 복원, 이 홀 멀리건, 앱 정보. 스코어카드에 있던 결과 보내기와 새 라운드 시작은 메뉴로 옮겼습니다.
  - +·−·벌타를 누르면 4초 동안 "드라이버 +1 · 되돌리기"가 뜨고, 누르면 그 홀이 누르기 전으로 돌아갑니다.
  - 홀 그림: 홀 설명에 "아일랜드"가 있으면 그린 둘레에 물을 그립니다(새별 7번). 그 밖에는 물·벙커를 그리지 않습니다.

  - 375×553 상세를 줄였습니다: 칩 줄 대신 홀 번호 아래에 "Par 4 · 376m", 클럽 이름 대신 숫자 옆 작은 클럽 아이콘, 벌타는 한 줄 알약 버튼. 이제 375×553과 375×667 모두 기본·상세가 스크롤 없이 들어옵니다.
  - 알약 숫자 크기가 알약 높이를 따라갑니다. 홀 설명 줄이 늘어 알약이 줄어도 숫자와 +/− 사이가 8px 아래로 내려가지 않습니다. 설명 줄은 700px 아래 화면에서 한 줄까지만 보입니다.
