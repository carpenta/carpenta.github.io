# Runtime dependencies

None. The bundle contains only code written in this package and `src/data/courses.json` (golf course pars taken from each course's own published scorecard; see Course data in DESIGN.md); the app uses no runtime CDN.

Development-only tools, pinned in package-lock.json: TypeScript 7.0.2 (Apache-2.0), Vite 8.3.3 (MIT), Vitest 5.0.3 (MIT), Playwright 1.64.0 (Apache-2.0).
